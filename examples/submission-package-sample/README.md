# 提出パッケージのサンプル

プロファイル `analysis-pilot` で生成した提出パッケージの見た目・構成の例です。

- 課題物理名: `京都-観光客の移動手段の不足`
- 生成スクリプト: `scripts/build_submission_package.py`
- 手順: `skills/ja/policy-submission-package/SKILL.md`
- 中身の定義: `docs/artifact-contracts.md` の「提出パッケージ」

## 同梱ファイル

| ファイル | 役割 |
|---|---|
| `京都-観光客の移動手段の不足.md` | 提出正本（Markdown） |
| `京都-観光客の移動手段の不足.pdf` | 提出用 PDF（リンク注釈付き） |
| `京都-観光客の移動手段の不足.html` | PDF 生成中間（任意） |
| `京都-観光客の移動手段の不足-マニフェスト.yaml` | プロファイル・含有セクション |

## 注意

- **実データの正本ではない。** 出典 PDF 全文や findings の完全セットは具体案リポ側に置く。本サンプルは提出用に要約・再構成した出力物のみ。
- 数値・制度記述はサンプル時点の公開情報に基づく要約であり、提出前には必ず具体案リポの正本と突き合わせること。
- 本スキル集への実課題データの書き込み禁止ルールは維持。サンプルは「出力の形」を示すための例外的同梱。
